# タロット占い（無料版 HTML）

無料で使えるタロット占い Web アプリケーション（HTML 単一ファイル版）

## 🎴 特徴

- **完全無料** - 登録不要、ネット接続ですぐ使える
- **ローカル動作** - すべての計算は端末内で完結
- **複数スプレッド対応** - ワンカード、スリーカード、ケルティックなど
- **AI 鑑定オプション** - Claude API キーを入力すれば AI による鑑定が可能
- **鑑定履歴保存** - ブラウザの履歴機能で過去の鑑定を確認できる
- **シンプルで美しい UI** - 神秘的で落ち着いた雰囲気のデザイン

## 🚀 使い方

1. サイトにアクセス：https://ran-lovely-you.github.io/tarot-v1
2. スプレッド（占い方式）を選択
3. 質問や相談内容を入力（オプション）
4. 「シャッフル」ボタンをクリック
5. カードが自動で引かれて鑑定文が表示されます

## 🤖 AI 鑑定について

Anthropic の Claude API キーを入力すると、AI による詳細で専門的な鑑定を受けられます。

- API キー入力欄から有効化
- キーはブラウザのローカルストレージに保存（外部送信なし）
- 有料サービスですが、自分のキーを使用するため、利用料はあなたが管理します

## 📋 動作環境

- モダンブラウザ（Chrome, Safari, Firefox, Edge など）
- JavaScript 有効
- インターネット接続
